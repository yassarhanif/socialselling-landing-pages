# Socialselling.id — Landing Page (V2)

Prototipe redesain beranda socialselling.id. Static site: HTML + CSS murni, tanpa build step.

## Deploy
Cloudflare Pages: framework preset **None**, build command kosong, output directory `/`.

## Isi
- `index.html` — beranda V2
- `favicon.svg` — ikon situs

## Catatan
